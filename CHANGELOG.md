# История изменений

## 1.6

- Публичная конфигурация Apple загружается через системный curl с проверкой TLS, ограничением параметров, размера и времени, с повторами GET.
- Подготовка до ввода пароля использует тот же путь получения конфигурации и идентичность Mac, что и реальный вход.
- Подготовка конфигурации, компонентов и сертификата ограничена общим сроком три минуты.

## 1.5

- Новый перенос с другого исходного телефона с сохранением архива и входа.
- Явная смена Apple ID и повторная проверка аккаунта перед загрузкой.
- Учёт владельца и исходного телефона в новых записях архива; совместимость со старыми записями.
- Один физический файл для совпадающих IPA с отдельными записями владельцев и источников.

## 1.4

- Системный HTTPS-транспорт для ограниченных SAP-адресов, предварительная проверка сертификата.
- Отдельная проверка полного служебного обмена без Apple ID.
- Обработка вставки кода 2FA с переносами, маркерами Terminal и невидимыми символами форматирования; повтор ввода при неверном формате.

## 1.3

- Закреплённый модуль ipatool с поддержкой обновлённого native endpoint Apple.
- Подготовка компонентов крупными диапазонами вместо множества мелких Range-запросов.
- Кэш проверенных компонентов, сообщения о прогрессе и ограничения времени.

## Первые версии

- Нативный интерфейс SwiftUI, список iPhone и приложений по USB.
- Авторизация, история покупок, загрузка и локальный архив IPA.
- Импорт и экспорт, SHA-256, проверки структуры IPA и установка через MobileDevice.framework.
